LifeBlend - Responsive Website </br>
A modern, responsive website built with HTML and CSS.

 Live Demo </br>
Visit the deployed site: https://alexandermultan.github.io/lifeblend/

 How to Run Locally </br>
 
Method 1: Simple File Opening </br>
Download this repository

Navigate to the LifeBlend folder on your computer

Double-click index.html and choose Chrome or another browser


Method 2: Using an IDE
Open the project in any IDE (VS Code, WebStorm, etc.)

Open index.html from the file explorer

Start the file using your IDE's built-in server or live server extension

For more detailed instructions on running websites locally, visit:
https://www.codedex.io/projects/run-a-website-locally-with-html
